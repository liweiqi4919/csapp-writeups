## 这两道题教我的东西

**01 压缩包** —— 压缩包说有密码，不代表真有密码。
ZIP 的每个文件项里有一个「加密标志位」。把它改成 1，7-Zip 就会弹密码框，但数据其实一点没加密。
判断真假的方法：看 `7z l -slt` 输出里的 `Encrypted` 字段，或者直接看文件头那几个字节。
→ 对应知识点：文件格式是**约定**，不是保护。凡是约定，就能被手动改。

**02 被揉坏的芙芙** —— 图片打不开，不一定是数据坏了。
PNG 开头是「标签」（IHDR 写明多宽、多高、什么颜色格式），后面才是像素数据，而像素数据是平铺的、没有分隔符——
**软件完全靠标签里的宽度决定每行折在哪**。宽度写小了，整张图就散架。
这道题的标签还被擦了「防伪码」（CRC32），而题目里那串 `051F503E` 正好就是它，于是可以反推回真实宽度。
→ 对应知识点：CRC 不是加密，是校验；反过来用，它是一次约束求解。
