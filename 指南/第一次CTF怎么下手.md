## 二、第一周主攻：**Misc（杂项）**

### 为什么从 Misc 开始

1. **不需要逆向、不需要编程基础** —— 多看多试就能上手
2. **最容易得分** —— 第一次比赛先尝到甜头
3. **工具就一个**：010 Editor + CyberChef

### Misc 最常见的 6 类题（按出现频率）

| 类型 | 题长什么样 | 第一步干什么 |
|---|---|---|
| **① 编码转换** | 给一长串 `4d5a90...` 或 `/=...` | **丢进 CyberChef**，试 Base64 / Hex / URL / ROT13 |
| **② 图片隐写** | 给一张图，说"里面有东西" | **看文件尾**（见下面口诀）、`strings` 搜 flag |
| **③ 文件头修复** | 给个文件打不开 | **看头几个字节**对不对（见下面表） |
| **④ 压缩包密码** | 给个 .zip/.rar 要密码 | CRC32 爆破 / 伪加密 / 明文攻击（**先看是不是伪加密**） |
| **⑤ 音频隐写** | 给个 .wav/.mp3 | 看频谱图（Audacity） |
| **⑥ 流量分析** | 给个 .pcap | Wireshark 打开，过滤器 `http` / `ftp` |

### ★ 口诀：Misc 四步走

```
1. file 一下：这到底是什么文件？
2. strings 一下：有没有直接能看到的 flag 或线索？
3. 丢 CyberChef：能自动解的全部解一遍
4. 看头看尾：文件头和文件尾有没有多余的东西？
```

**Linux 里的 `file` 和 `strings` 命令，在你 WSL 里现成就有**：

```bash
file 题目文件
strings 题目文件 | grep -i flag
strings 题目文件 | grep -i ctf
```

**`file` 看真实类型**（不怕改后缀名骗你），**`strings` 把所有可见字符揪出来**（**很多简单题的 flag 就明晃晃躺在那儿**）。

### 常见文件头速查（改后缀名骗人的题就靠这个）

| 文件类型 | 开头几个字节（十六进制） | 对应字符 |
|---|---|---|
| **PNG** | `89 50 4E 47` | `.PNG` |
| **JPEG** | `FF D8 FF` | — |
| **GIF** | `47 49 46 38` | `GIF8` |
| **ZIP** | `50 4B 03 04` | `PK..` |
| **RAR** | `52 61 72 21` | `Rar!` |
| **7z** | `37 7A BC AF` | `7z..` |
| **PDF** | `25 50 44 46` | `%PDF` |
| **ELF**（Linux 程序） | `7F 45 4C 46` | `.ELF` |
| **EXE / PE**（Windows 程序） | `4D 5A` | `MZ` |

**记住最有用的两个**：

- **`4D 5A` = `MZ` = Windows 可执行文件** ← **Reverse 题全是这个**
- **`50 4B` = `PK` = ZIP 压缩包**

**⚠️ 一个经典坑**：**有些题把 flag 藏在 `IEND` 之后的"文件尾多余数据"里**（PNG 的正常结束标志是 `IEND`）。**在 010 Editor 里拉到文件末尾，看 `IEND` 后面还有没有东西。**

### Misc 的纪律

**卡住超过 1 小时，立刻换题。**

**Misc 的特点是"想到就很简单，想不到就卡死"，而线索往往在你想不到的地方。别耗。**

## 三、第二周起：**Reverse（逆向）**，只做最简单的

### 学长的流程，照做就行

```
1. DIE 先看一眼：几位的程序？什么编译器？有没有加壳？
2. IDA 打开：找 main 函数 → 找字符串 → 看伪代码
3. 伪代码看不懂 → 让 AI 逐行解释（不是让它替你做题）
4. 卡住 → 搜「?CTF 2026 题目名 WP」
```

### Reverse 的关键认知

**① `IDA` 生成的伪代码「大多接近 C 语言」**

**所以你这两天学的 `if` / `switch`，就是 Reverse 的地基。** 你在 IDA 里会看到的不是"天书"，是**长得有点像 C 的东西**：

```c
int __cdecl main(int argc, const char **argv, const char **envp)
{
  char input[32];
  printf("input: ");
  scanf("%s", input);
  if ( strcmp(input, "ahuctf{...}") == 0 )
    puts("correct!");
  else
    puts("wrong!");
  return 0;
}
```

**这题你现在就能看懂** —— 它让你输入一个字符串，然后和某个值比较，相等就对。**你只要在 IDA 里找到那个被比较的字符串就行了。**

**② 汇编只需要"看得懂"，不需要"写得出"**

> 学长的原话：**刚开始不需要自己手写复杂汇编，重点是能看懂**：数据从哪来、经过了什么操作、程序会跳到哪。

**③ 遇到这些常见函数要认出来**

| IDA 里看到 | 意思 |
|---|---|
| `main` | 主函数，**先找它** |
| `printf` / `puts` | 输出 |
| `scanf` / `gets` | 输入（`gets` 有漏洞，Pwn 题的入口） |
| **`strcmp`** | **字符串比较** ← **「输入 == flag」型题的标志** |
| `strlen` | 算长度 |
| `memcmp` | 内存比较（比 strcmp 更底层） |

**看到 `strcmp`，八成就是"输入对了就给 flag"** —— **去比较的两个东西里面找 flag。**

## 四、纪律四条（贴在显示器上）

| 纪律 | 原因 |
|---|---|
| **① 卡住超过 1 小时 → 立刻换题** | 四周每周出新题，死磕一题会少拿 5 道简单题的分 + 5 篇 writeup |
| **② 每解出一道题，当天就写 writeup** | 隔天记忆会糊，补写要花三倍时间 |
| **③ 先做能做的，不碰 Web/Pwn** | 你现在的 C 基础够 Misc 和简单 Reverse；**Web 需要 HTTP/前端知识，Pwn 需要汇编和栈** |
| **④ 用 AI 的方式：问"这里为什么"，不问"答案是啥"** | 学长的原话，也是你自己立的规则 |

### 关于第 ④ 条的诚实提醒

**我没有办法验证你比赛时怎么用 AI。** 但有一条是硬的：

> **如果 flag 是 AI 直接告诉你的，那道题的 writeup 你写不出来。**
> **而 writeup 是你这次比赛唯一能带走的东西。**

**所以这条纪律不需要别人监督 —— 它自己会结算。**
